- **需求**：看板上可以切换股票池（如沪深300交易池、中证500交易池），看所有因子在该池子下的指标和排名。
- **现状**：全局只有一套标准口径（`[web.standard]`，默认基础交易池 `univ_trade_base`），只能改配置后重启；新建评估抽屉里能选别的股票池，但结果不进看板主表。

- **待定**：
  - 只换股票池，还是允许起始日、持有期等也一起切换。
  - 与 `claude/workbench-ui-626078` 上提交 eac5469（看板默认取最新 run + 评估来源选择器）的口径冲突如何取舍。

### 因子生命周期状态管理

- **问题**：因子数据构建出来后，可能还没评估、正在评估或评估失败，目前没有地方能看到每个因子处在哪一步。
- **当前做法**：看板只显示已有标准评估的因子，未评估的不显示。
- **待定**：状态有哪些（已构建 / 评估中 / 已评估 / 失败等），在哪里查看，是否在看板外单独提供“待评估”列表。
- 记录于 2026-11-08。

### 实验中使用了不同评估设定时，看板如何处理

- **问题**：看板默认取每个因子的最新评估；做实验时可能用了与标准口径不同的设定（如 5 组、固定截止日），这时最新结果和其他因子不可直接比较。
- **当前做法**：先假设只有一套固定评估标准，看板固定取最新，不提供评估来源选择。
- **待定**：最新评估设定不同时，是显示并标出差异，还是退回该因子最近一次标准评估。
- 记录于 2026-11-08。
