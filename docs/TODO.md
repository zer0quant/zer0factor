- **需求**：因子增量更新，只追加新交易日的因子值；评估增量更新，只补算新日期，合并进已有 run，或生成新的统一口径 run。

- **状态（2026-11-10）**：已实现 `update-daily`、`check-freshness`、各计算命令的 `--incremental` 和增量评估，用法见 [docs/incremental-update.md](incremental-update.md)。剩余：

### 因子生命周期状态管理

- **问题**：因子数据构建出来后，可能还没评估、正在评估或评估失败，目前没有地方能看到每个因子处在哪一步。
- **当前做法**：看板只列主版本有标准评估的原始因子；其余收在“另有 N 个待处理”里，标“待评估 / 待中性化 / 方向不一致”；因子主页的周期按钮标出各版本是否已评估。
- **待定**：状态有哪些（已构建 / 评估中 / 已评估 / 失败等），在哪里查看，是否在看板外单独提供“待评估”列表。
- 记录于 2026-11-08。

### 实验中使用了不同评估设定时，看板如何处理

- **问题**：看板默认取每个因子的最新评估；做实验时可能用了与标准口径不同的设定（如 5 组、固定截止日），这时最新结果和其他因子不可直接比较。
- **当前做法**：先假设只有一套固定评估标准，看板固定取最新，不提供评估来源选择。
- **待定**：最新评估设定不同时，是显示并标出差异，还是退回该因子最近一次标准评估。
- 记录于 2026-11-08。
